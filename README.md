Arduino Smart Robot Car Project

******Project Description**********

This project is a Smart Robot Car using Arduino Uno. The car can be controlled using Bluetooth and can also move automatically using an ultrasonic sensor to avoid obstacles.

->Components Used:

1-Arduino Uno
2-L298N Motor Driver
3-DC Motors
4-HC-05 Bluetooth Module
5-Ultrasonic Sensor (HC-SR04)
6-Servo Motor
7-LCD Display
8-18650 Batteries

->Features
Bluetooth Control
Automatic Obstacle Avoidance
Multiple Driving Modes
LCD Display

->Programming
The project was programmed using Arduino C++.
